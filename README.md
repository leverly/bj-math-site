# 北京中考数学领航

把北京中考数学做成一个**按方法组织、按步骤判定、按错因诊断**的静态备考站。纯 HTML/CSS/JS，无 CDN、无外链、断网可玩，`file://` 双击直接打开。

当前版本：**P1 送分区版**。18 章、29 张方法卡、**300 题**、170 概念卡（356 个判断）、94 条公式定理。覆盖卷面送分区 58 分与中档区主要题型。完整规划见 [PLAN.md](PLAN.md)。

## 直接打开

```bash
open index.html      # 双击也行，无需服务器、无需构建
```

## 这个版本验证了什么

理科站与英语站最大的差别不在页面，而在三个技术难题。P0 的唯一目的就是把这三件证明掉：

| 难题 | 方案 | 实测 |
|---|---|---|
| 公式能否离线渲染 | 构建期 MathJax v3 → 内联 SVG，全局字形缓存 | 20/20 通过，单条 1.4 KB |
| 几何图能否声明式生成 | 数据写坐标 + 元素类型，构建期编译成 SVG | 6/6 通过，单图 1.6 KB |
| 解答题能否步骤级判定 | 判定的单位是「步」不是「题」，记 `stuckStep` | 三模式跑通 |

### 为什么不能用四选一

英语站判 `{id, ok}` 就够了。理科不行——「做错了」不是一个信息，**错在哪一层**才决定下一步练什么：

| 错因 | 补救动作 | 出册规则 |
|---|---|---|
| `concept` 概念不清 | 回概念卡做条件判断题 | 该卡连对 2 次 |
| `method` 方法未掌握 | 看方法卡识别信号 + 母题 | 3 个变式全对 |
| `construct` 构造不出 | 看构造模型库 | 同模型另 1 题做对 |
| `calc` 计算失误 | 进计算专项限时练 | **连对 3 次** |
| `express` 表达不规范 | 做找错练习 | 该题型 2 次 |

所以运行时记录是四元组而不是二值：

```js
{ id, result, stuckStep, errorType, timeMs, variantOf }
```

## 页面

| 页面 | 作用 |
|---|---|
| `index.html` | 首页：三层分区、方法卡入口、学习驾驶舱 |
| `concept.html` | **概念自测**：只考条件不考背诵，356 个判断 |
| `drill.html` | **分步刷题**：引导模式（逐步作答）/ 自查模式（先做后对） |
| `method.html` | 方法卡索引：按「识别信号」搜索，不按章节 |
| `method/<id>.html` | 单张方法卡：信号 → 步骤 → 误用 → 母题 → 变式链 |
| `map.html` | 知识图谱：章节 + 前置依赖边 |
| `map/<chapter>.html` | 单章页：本章方法卡、题量、前置章提醒 |
| `graph.html` | 公式定理库：含**适用条件**与**常见误用**两列 |
| `wrong.html` | 错因诊断：五类分栏，各给不同补救 |
| `content.html` | 内容与口径说明、判分边界、档案备份 |

## 三种作答模式

| 模式 | 场景 | 行为 |
|---|---|---|
| `guided` 引导 | 刚看完方法卡 | 逐步给 ask，答对进下一步，答错立刻给提示 |
| `selfcheck` 自查 | 练解答题 | 只给步骤骨架（动词短语），用户勾「做出来/卡住」，卡住给分层提示 |
| `timed` 限时 | 整卷（P5） | 不打断，交卷后统一判 |

**自查模式是全站的取舍核心**：放弃解答题自动判分，换取过程诊断。给的是「你卡在第 2 步」这种真数据，而不是一个可能是错的机器判分。

## 数据投递

英语站把数据内联进每个页面（只有 304 题）。理科约 1050 题、每题带 steps 与解答，全站 6–9 MB，**不能内联**。

改为构建期输出 classic script 分片 `dist/data/ch/<chapter>.js`（`window.BJM.CH['ch-x'] = {questions, concepts, defs}`）。classic `<script src>` 在 `file://` 下正常，只有 ES module 会被拦。

**按章分片而不是按层分片**：按 tier 切会得到 672 KB 的单片，按章切最大 212 KB。单章页只加载自己那份。

题目里的公式与图形**在构建期就渲染成 SVG 内联进分片**，运行时零依赖、零渲染成本。

**每个分片自带字形 defs**：这是必须的——构建期渲染的 `<use href="#MJX-...">` 依赖共享 defs，drill 页动态加载分片时页面本身没有这些 defs，公式会全部不可见。

## 构建与校验

```bash
node build-site.mjs          # 生成全站，打印规模与体积报告
node tools/validate.mjs      # 11 类内容校验，失败退出码 1
node tools/mj-decide.mjs     # 公式 20 条决策测试
node tools/fig-test.mjs      # 图形 6 张 + 生成 tools/fig-preview.html
```

`build-site.mjs` 会检查体积预算（首页 ≤ 200 KB、drill ≤ 500 KB、方法卡 ≤ 400 KB），超了打警告。

## 技术要点（踩过的坑）

这几条写在代码注释里，改动时务必遵守：

1. **`fontCache` 必须用 `global` 不能用 `local`** —— local 让每条公式重复内联字形路径，体积从 1.4 KB 涨到 4.3 KB。
2. **`fontCache.defs` 是 LiteElement 对象，不是字符串** —— 必须 `adaptor.outerHTML()` 序列化。
3. **defs 是累计的** —— 每页必须用独立渲染器实例，只渲染该页公式，否则 defs 膨胀到全站字形总量。
4. **图形内嵌公式必须返回裸 `<svg>`** —— `<span>` 是 HTML 元素，放进 SVG 会被忽略，内层 svg 失去定位。
5. **不用 `foreignObject`** —— `file://` 下会错位或不可见。
6. **不用 `dominant-baseline="middle"`** —— 在继承自 `<g>` 的上下文里会让 12px 字形塌缩到几乎不可见。用 `y + 4` 显式基线偏移。
7. **`pt` 的 `pos` 是标签方位不是 `text-anchor`** —— `tl`/`tr`/`bl`/`br`/`l`/`r`/`t`/`b`/`c`。
8. **`angle` 必须画劣角** —— 把 `a2-a1` 归一到 `(-π, π]`，否则会画出优角。
9. **SVG y 轴向下** —— 抛物线 `y=x²` 开口向上要写 `vy = 顶点y - t²·k`。
10. **英语站 CSS 的 `.trap .bad::before` 会注入「✕ 易错：」** —— 理科站在标记里已写 `mark`，需覆盖关掉注入。
11. **分片必须自带字形 defs** —— 动态加载的分片若不带 defs，公式全部不可见。
12. **不能快照 `window.BJM.CH`** —— 分片异步加载，闭包快照会永远指向空对象。
13. **选项必须构建期渲染** —— 引擎里 `esc(o)` 会把 `$\sqrt{8}$` 当纯文本显示，数据里加 `optionsHtml`。
14. **SVG 属性用单引号** —— MathJax 输出双引号，塞进 JSON 会转义成 `\"`，体积翻倍。`compact()` 处理，JSON 后省 31%。

## 已知限制

- **例题为原创，非真题**，按北京卷题型结构编写。
- **解答题不自动判分**，走自查模式。全站不出现「AI 批改」字样。
- **不做动态几何**，动点用「三帧快照」表达临界。
- **不宣称覆盖全部考点**——理科题目无穷变式，只标注每块分值与当前题量。
- 学习记录存 `localStorage`（`bj-` 前缀），换设备需在「内容说明」页导出档案。
- 当前 18 章、29 张方法卡、300 题、170 概念卡、94 条公式。P2 目标：42 张方法卡 + 220 条公式。
